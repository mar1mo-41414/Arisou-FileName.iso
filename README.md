# Arisou-FileName.iso

**ありそうで、なさそうなファイル名**を、気の向くままに作る Web ツールです。

> [!NOTE]
> これはおもちゃです。実際にファイルを作ったり、同名ファイルの存在を調べたりはしません。実務や安全性が必要な用途を想定していません。

## できること

- ゲーム、実行ファイル、映像、画像、音声、データ、圧縮ファイルなどの雰囲気で名前を生成
- 英小文字・英大文字・数字・記号 (`_` / `-`) と、名前・拡張子それぞれの文字数を選択
- 拡張子は種類に合うものから選ぶ / 入力した値に固定 / 完全ランダム / テキストファイルのセットから選択
- 8.3 形式や、末尾に `~1` を付けるレトロ風ルールを有効化
- 一度に最大20件生成し、個別またはまとめてコピー

生成はブラウザ内で完結します。サーバーへの送信や、ファイルの作成は行いません。

## 使い方

`index.html` をブラウザで開くだけです。インストールやビルドは不要です。

```bash
git clone https://github.com/mar1mo-41414/Arisou-FileName.iso.git
cd Arisou-FileName.iso
# index.html をブラウザで開く
```

1. ファイルの種類、使用する文字、文字数、拡張子の選び方を設定します。
2. 必要なら特別なルールと生成数を選び、「ファイル名を生成」を押します。
3. 結果をクリックすると個別に、「すべてコピー」で改行区切りでコピーできます。

コピー機能はブラウザのクリップボード機能を使います。利用できない環境ではブラウザの従来のコピー機能を試します。

### 拡張子セットを使う

「拡張子」から「ファイルから」を選び、拡張子を1行に1つ書いた UTF-8 のテキストファイルを選択します。ファイルの拡張子は `.txt`、`.list`、`.dic`、`.dict`、`.dicts` に対応しています。いずれも同じテキスト形式として読み込みます。

```text
jpg
.png
tiff
```

空行と各行の前後の空白は無視され、先頭の `.` はあってもなくても構いません。重複した行はその分選ばれやすくなります。ファイルはブラウザ内で読み込み、送信・保存しません。

指定した文字種・拡張子の文字数に合う行からランダムに選びます。ファイルの種類は名前の雰囲気にのみ影響します。8.3 形式では拡張子を大文字にしたうえで、3文字以内の条件に合うものを選びます。候補がない場合は設定を調整してください。行の途中のドット・空白・スラッシュは使えません。

### ルールについて

- 文字数はドットを含みません。名前は1〜32文字、拡張子は1〜10文字の範囲で指定します。
- 「種類から選ぶ」は、選択した種類の拡張子のうち、指定した文字種と文字数に合うものを選びます。候補がない場合は条件を変更してください。
- 「固定する」では先頭のドットを除いた入力値をそのまま使い、拡張子の文字種・文字数設定は無視します。8.3形式では大文字に変換し、3文字以内の対応文字に限ります。
- 8.3 形式では名前を最大8文字、拡張子を最大3文字に制限し、英字を大文字にします。選択した最小文字数が上限を超える場合はエラーになります。これは短い名前を楽しむための簡易ルールで、実際のDOSファイル名への変換や重複確認はしません。
- `~1` は名前の文字数に含まれます。最低2文字が必要です。このルールを選ぶと、文字種に数字を含めていなくても `~1` が付きます。
- 条件によっては単語の代わりにランダムな文字列になります。結果の重複もありえます。

## テスト
